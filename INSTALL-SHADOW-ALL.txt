QUASAR × SHADOW — INSTALLATION
================================

التشغيل المحلي:
1) فك الضغط في مجلد مستقل.
2) ثبّت الاعتماديات من جذر المشروع: npm ci
3) اضبط PANEL_PASSWORD في متغيرات البيئة (12 حرفاً على الأقل).
4) شغّل اللوحة: npm start
5) افتح http://127.0.0.1:3001/shadowxdiablos
6) ارفع ملف جلسة مستقل لكل حساب من بطاقة الجلسة، ثم شغّل الجلسة يدوياً.

المحرك الوحيد هو SHADOW/index.js. يدعم النظام الجلسات 1 و2 و3، ولكل جلسة ملفات منفصلة:
appState.json / appState2.json / appState3.json
و data.json / data2.json / data3.json.
لا تنسخ بيانات جلسة إلى جلسة أخرى.

الأوامر النشطة:
- اسم: تغيير اسم المجموعة وحفظه للحماية.
- كنيات: تغيير كنيات أعضاء المجموعة وحمايتها مع استثناء المطورين والبوت.
- بايو: تغيير بايو حساب البوت.
- حذف: حذف رسالة البوت التي ترد عليها.
- خروج: إيقاف مؤقتات المجموعة وإخراج البوت منها.
- بيس [النص] [الثواني]: تكرار مضبوط، بحد أدنى 60 ثانية.
- اتوميك [النص]: تكرار كل 120 ثانية.
- محرك 1/2/3 [النص]: تكرار كل 60/90/120 ثانية.
- command load: فحص وإعادة تحميل الأوامر دون تنفيذها.
- help و uptime.

بيس واتوميك ومحرك تستخدم حجزاً مشتركاً؛ لا يعمل أكثر من نظام تكرار واحد في المجموعة نفسها. أول رسالة هي النص المطلوب نفسه ولا توجد رسالة تفعيل منفصلة. الإيقاف عبر أمر النظام متبوعاً بكلمة إيقاف.

Railway:
راجع RAILWAY-DEPLOY-AR.md. أنشئ Volume عند /data واضبط SHADOW_DATA_DIR=/data، ثم أضف PANEL_PASSWORD وDEV_ID في Variables. الخدمة تستخدم npm start وتوفر /api/health.

حماية البيانات:
- لا تضع appState أو cookies أو config.json أو data*.json أو ملفات .env في مستودع Git.
- لا ترسل بيانات الجلسة عبر Telegram.
- يستدعي المحرك relogin الداخلي عند اكتشاف أخطاء المصادقة إذا دعمته المكتبة، ولا يستخرج أو يطبع cookies تلقائياً.
- لا يتخطى checkpoint أو حظر المنصة.

الفحص:
node --check لكل ملفات JavaScript ثم npm test.
لم يتم تشغيل أي بوت أثناء إعداد هذه النسخة.
